CONTROLES Y RIVALES

JUGADOR 1 W A S D + ESPACIOJUGADOR 2 ↑ ← ↓ → + ENTERJUGADOR 3 I J K L + UJUGADOR 4 T F G H + YREINICIAR RPAUSA ESCVISTA C

W / ↑ acelera · S / ↓ frena · A/D o ←/→ gira. P3 usa I/K para acelerar/frenar, J/L para girar y U para derrapar. P4 usa T/G, F/H e Y. El freno completo tiene prioridad aunque mantengas acelerar. Podés elegir mandos en la parrilla local; soltar RT gradualmente aumenta la retención. Para retroceder, detenete y mantené el freno con el acelerador suelto; acelerá para volver hacia adelante.
